
# Fake Review Detection

## Project Overview
A Data Mining project that uses text mining and machine learning to classify online product reviews as potentially fake or genuine.

## Technologies
- Python
- Pandas and NumPy
- NLTK
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Planned Features
- Review data cleaning
- Text preprocessing and TF-IDF
- Fake review classification
- Model evaluation
- Interactive dashboard
